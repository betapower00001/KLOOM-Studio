KLOOM Studio - แพตช์ลดช่องกรอกตัวอย่างผลงาน

สิ่งที่เปลี่ยน
- ล็อกตัวอย่างผลงานไว้เพียง 3 หมวด
- ไม่มีปุ่มเพิ่มหรือลบหมวด
- ซ่อนหมวดหมู่, Alt text, URL รีวิว, ลำดับ และสถานะเผยแพร่
- แสดงเฉพาะ รูปปก, ชื่อหมวด, คำอธิบาย, บันทึก และดูหน้ารีวิว
- ระบบจะกำหนด /review/1, /review/2, /review/3 และลำดับให้อัตโนมัติ
- ภาพรีวิวภายในแต่ละหมวดยังจัดการได้จากส่วนด้านล่าง

วิธีติดตั้ง
1. แตก ZIP
2. คัดลอกทุกไฟล์ด้านในไปวางทับโฟลเดอร์โปรเจกต์ที่มี package.json
3. ดับเบิลคลิก APPLY_PORTFOLIO_SIMPLE_ADMIN_WINDOWS.bat
4. รัน npm run dev
