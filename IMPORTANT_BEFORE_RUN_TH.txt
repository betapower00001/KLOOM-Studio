KLOOM Studio — อัปเดตเฉพาะระบบหลังบ้าน
========================================

สิ่งที่เปลี่ยน
- เมนู "รีวิวลูกค้า" ในหลังบ้านถูกเปลี่ยนเป็น "ตัวอย่างผลงานของเรา"
- เพิ่มรูป ชื่อผลงาน คำอธิบาย หมวดหมู่ Alt text ลำดับ และสถานะพร้อมเผยแพร่ได้
- หน้าเว็บไซต์เดิมและไฟล์ส่วนหน้าไม่ได้ถูกแก้ไข
- รีวิวที่หน้าเว็บไซต์เดิมยังคงทำงานเหมือนเดิม เพราะผู้ใช้สั่งไม่ให้แก้ส่วนหน้า

วิธีใช้งานที่แนะนำ
1. แตก ZIP ลงในโฟลเดอร์ใหม่
2. คัดลอกไฟล์ .env.local จากโปรเจกต์ที่ใช้อยู่มาไว้ข้าง package.json
3. เปิด CMD ในโฟลเดอร์ใหม่ แล้วรัน npm ci --no-audit --no-fund
4. ดับเบิลคลิก APPLY_PORTFOLIO_BACKEND_WINDOWS.bat
5. รัน npm run dev
6. เข้า http://localhost:3000/admin/portfolio

ถ้าจะแตกไฟล์ทับโฟลเดอร์เดิม
- สำรองโฟลเดอร์เดิมก่อน
- แตกไฟล์ทับ แล้วดับเบิลคลิก APPLY_PORTFOLIO_BACKEND_WINDOWS.bat
- ไฟล์นี้จะลบเฉพาะระบบจัดการรีวิวเก่าของแอดมิน ไม่แตะหน้าเว็บไซต์

หมายเหตุ
- ไฟล์ดาวน์โหลดไม่รวม .env.local เพื่อไม่ให้รหัส Neon และ Blob Token รั่วไหล
- การเพิ่มตาราง portfolio_items ไม่ลบข้อมูลเดิม
- ข้อมูลในเมนูใหม่ยังไม่ถูกดึงไปแสดงหน้าเว็บไซต์ตามคำขอ
