KLOOM Studio — ระบบภาพรีวิวแยก 3 หมวด

ระบบนี้เพิ่มในเมนูหลังบ้าน: ตัวอย่างผลงานของเรา
- หมวด 1 เชื่อมกับ /review/1
- หมวด 2 เชื่อมกับ /review/2
- หมวด 3 เชื่อมกับ /review/3

ความสามารถ
- อัปโหลดหลายรูปพร้อมกัน (สูงสุด 30 รูปต่อครั้ง)
- แสดงภาพตัวอย่างในหลังบ้าน
- แก้คำอธิบายรูป
- จัดลำดับรูป
- เปิด/ปิดการแสดงผล
- ลบรูปจากแกลเลอรี
- รูปใหม่เก็บใน Vercel Blob
- ดึงรูปเดิม /review/reviwe-1.jpg ถึง reviwe-180.jpg เข้าฐานข้อมูลทั้ง 3 หมวด

วิธีติดตั้งแพตช์
1. แตก ZIP แล้วคัดลอกไฟล์ทั้งหมดไปวางทับโฟลเดอร์โปรเจกต์เดิม
2. ดับเบิลคลิก APPLY_REVIEW_GALLERY_WINDOWS.bat
   หรือรัน: node scripts\apply-review-gallery.mjs
3. รัน npm run dev
4. เปิด http://localhost:3000/admin/portfolio
5. เลื่อนลงไปที่หัวข้อ "ภาพรีวิวในแต่ละหมวด"

หมายเหตุ
- ต้องมี DATABASE_URL และ BLOB_READ_WRITE_TOKEN ที่ถูกต้องใน .env.local
- แพตช์ไม่ลบไฟล์รูปเดิมใน public/review
- หน้ารีวิวยังคงหน้าตาเดิม เปลี่ยนเฉพาะแหล่งข้อมูลเป็น Neon
