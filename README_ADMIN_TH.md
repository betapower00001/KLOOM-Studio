# ระบบหลังบ้าน KLOOM Studio

เข้าใช้งานที่ `/admin/login`

## ฟังก์ชัน

- Dashboard สรุปจำนวนสินค้า สี/ราคา บทความ และตัวอย่างผลงาน
- จัดการหมวดขนาด สินค้า ตัวเลือกสี ราคา รูป และอุปกรณ์เสริม
- จัดการบทความและสถานะเผยแพร่
- จัดการ **ตัวอย่างผลงานของเรา**: รูปภาพ ชื่อ คำอธิบาย หมวดหมู่ Alt text ลำดับ และสถานะพร้อมเผยแพร่
- แก้ Hero และข้อมูลติดต่อ
- อัปโหลดรูป JPEG, PNG, WebP หรือ GIF ขนาดไม่เกิน 10 MB ไปยัง Vercel Blob
- เปลี่ยนชื่อ อีเมล และรหัสผ่านผู้ดูแลจากเมนู **บัญชีผู้ดูแล**

> เมนูตัวอย่างผลงานจัดเก็บข้อมูลในระบบหลังบ้านเท่านั้น และยังไม่เชื่อมกับหน้าเว็บไซต์เดิมตามคำขอ

## หลังอัปเดตไฟล์

รันคำสั่งนี้หนึ่งครั้งเพื่อเพิ่มตารางตัวอย่างผลงาน โดยไม่ลบข้อมูลเดิม:

```bat
npm run db:schema
```

หรือดับเบิลคลิก `UPDATE_PORTFOLIO_DATABASE_WINDOWS.bat`

## ผู้ดูแลคนแรก

ตั้งค่า `INITIAL_ADMIN_EMAIL` และ `INITIAL_ADMIN_PASSWORD` ก่อนล็อกอินครั้งแรก ระบบจะสร้างผู้ดูแลใน Neon และเก็บรหัสผ่านแบบ bcrypt hash

หลังล็อกอินสำเร็จ:

1. เปิดเมนู **บัญชีผู้ดูแล** และเปลี่ยนรหัสผ่านตามต้องการ
2. ลบ `INITIAL_ADMIN_EMAIL` และ `INITIAL_ADMIN_PASSWORD` จาก Vercel
3. Redeploy

ต้องเก็บ `AUTH_SECRET` ไว้ตลอด เพราะใช้ตรวจสอบคุกกี้ล็อกอิน
